Stable controller states were preserved as Golden, Diamond, Platinum and Platinum V2 validation checkpoints, with source and compact run evidence archived in the project repository (Raj, 2026).

Raj, S. (2026) *Intelligent Robotics Maze Navigation: technical artefacts and validation baselines*. GitHub repository. Available at: https://github.com/shubhamraj-ai/intelligent-robotics-maze-navigation (Accessed: 13 November 2026).
